# ONE:2:US

A mobile-first dating app prototype built around a transparent pay-per-use model, curated matches, real-world events, and a simple wallet.

## Features

- Curated discovery instead of endless swiping
- Pay only for actions you actually use
- Match, chat, event and wallet prototype flows
- Mobile-first responsive UI
- Ready for GitHub Pages deployment

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Tech

React + Vite, no backend required for the prototype.
